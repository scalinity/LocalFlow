# Generator comparison

The page answers whether Haiku can supply useful cleanup-training labels at a
lower cost. It separates generation quality from verifier behavior and from
downstream fine-tuned model quality, which this small comparison cannot prove.

Use a restrained editorial comparison: a large serif question, three aligned
model columns, one compact quality-versus-cost figure, and an expandable reading
desk with the shared brief above each model's independently generated pair.
Reuse LocalFlow's paper, ink, and teal palette, adding rust for Haiku and plum
for Opus. Use local Iowan and Avenir font stacks so the page works offline.

Order: measured verdict and cost difference; acceptance and category coverage;
verifier disagreement; actual examples; an explicitly labeled budget projection;
method, exact usage, and limitations. All figures come from the saved batch
receipts and returned labels. Do not substitute illustrative data for results.

The three output columns collapse into labeled rows on small screens. Support
light and dark appearances, keyboard controls, search, category and verdict
filters, and text equivalents for charts. No external scripts, assets, fonts,
or automatic network requests. Inspect both appearances and a phone-width tab.

Review against the brief: showing the shared brief avoids implying that the
models received identical source dictation; each generates a complete pair.
Separating verifier cost prevents the 20x token-price difference from being
misread as a 20x reduction in the cost of accepted, checked training examples.
