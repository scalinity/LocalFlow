## What shipped

1. **The normalizer (Spec S10, EV-06).** `localflow/v2/normalize`: a deterministic, model-free, stdlib-only package. Typed grammars for integers (technical contexts, prose guards), decimals/signs (exact `Decimal`, significant zeros preserved), percentages and percentage points, currency (locale symbols, `12.000€` under es-ES, word kept when the locale lacks a symbol), month-name dates (invalid days flagged, numeric dates never touched), clock times (no invented meridiem), codes/phones (leading zeros preserved, no country code), versions (anchored, components validated, unanchored multi-point flagged), IPs/ports (invalid octets flagged and region-locked), dimensions/units (`10 × 20 cm`, MB vs Mb distinct in evidence), identifiers (context-fed only), dotfiles, anchored spoken paths, spoken domains/email (known TLDs), registered slash skills (exact spelling, multiword aliases, unknown → literal + retained review suggestion), symbol commands with idiom/noun-compound guards, Markdown structure commands, shell flags/pipes (text only), and the literal escape ("write the word slash" → `slash`).
2. **Typed-span precedence and the edit ledger.** Layers: literal escape → protected syntax (quote zones; already-written forms cannot re-match) → registered skills → typed grammar → context vocabulary. Conflicts resolve by `(layer, longer span, position, class)` — never substitution order; overlapping or differing-output same-span proposals are rejected and retained with reasons (`overlap_conflict`, `ambiguous_same_span`, `unknown_skill`, `invalid_octet`, `invalid_day`, `invalid_version`, `unanchored_version`, `protected_span`, `flagged_region`). All offsets are zero-based half-open Unicode code points. `replay(input)` reproduces the output from the ledger alone; `is_idempotent(policy, context)` reports the honest bool.
3. **Pipeline integration (parent process).** `app.py`'s coordinator thread runs normalization between ASR and cleanup (`transcribing → normalizing → cleaning`); cleanup receives the normalized text; cleanup-off applies the normalized text; any parser exception passes the raw transcript through (`normalization.failed` event, `raw_passthrough`); a policy-load failure disables the stage with an event, never a startup crash. Config: `normalization_profile` (`technical` default | `standard` | `off`), `normalization_locale` (`en-US` default, `es-ES` supported). The M03 worker protocol is unchanged.
4. **Training evidence (S29.4 family, EV-19).** `on_normalization_result` writes the normalized-text and full-ledger artifacts (parent = raw transcript, lease-governed) and populates the envelope's `normalization` block: policy revision (hash of canonical policy-file content + locale + profile + registrations), per-edit ops/values/units/spans, counts, idempotence (evaluated with the pass-1 context; null-with-reason on failure). Envelope values are typed numerics only — string-valued command classes keep their strings in the ledger artifact (S29.14). Without the stage, the honest `not_captured_at_stage` reason remains.
5. **Fixtures and scoring.** Exactly 80 numeric + 60 syntax owning fixtures (34 negative controls; the two literal-escape idempotence corners declared per-fixture), 24 short-command text counterparts, the ITN-independent `score_command_corpus` (exact-token accuracy 16/16, false-command rate 0/8) and `separate_scores` (number-word→digit apart from other edits), and the `preview_phrase` test-phrase API for the future Dictionary/Developer UI.

## Contracts and decisions

- New `contracts/normalization.md` (placement, policy/context objects, ledger schema, precedence, the full grammar behavior reference including guards and documented limitations, evidence fields, M05/M06 dependencies); `contracts/INDEX.md` row + decision note; `contracts/training_evidence.md` M04 live status. No frozen identifier repurposed; registry unchanged (33/22); no ADRs — no spec deviation accepted.
- **Where normalization runs (settled, per the kickoff):** the parent process, coordinator thread. S06's subprocess isolates Metal/MLX faults; normalization holds no MLX state, so it gains no protocol op and never queues behind the supervisor's GPU lock. The S24 budget is met with 5.9× headroom.
- **The literal-escape/idempotence corner:** an escape whose object is or contains a command word/phrase ("write the word comma" → `comma`) is not stable under a second full pass; the pipeline re-normalizes only raw ASR output, both corner fixtures declare `idempotence_expected: false`, and `is_idempotent()` reports it per record. Everything else is idempotent by construction (grammars match spoken word forms only).
- **Unanchored slash chains stay prose** ("slash the budget") — spoken-path conversion is anchor-gated; full path dictation waits for M06 destination context.
- ES scope honestly bounded: numbers/percent/currency/dates covered; ES punctuation command names and 'punto'-joined versions are documented limitations (fixtures LF-SYN-059/060 assert the literal outcomes).
