## What shipped

1. **Dated event logging (Spec S07, EV-02).** `localflow/v2/eventlog.py`: JSONL envelope schema version 2 under `~/Library/Logs/LocalFlow/events-YYYY-MM-DD.jsonl` (0700 dir / 0600 files), size roll at 10 MiB + UTC-day boundary with age-monotonic suffixes, 14-day/100 MiB retention that keeps files mentioning unresolved jobs and never manages a second writer's pid-prefixed files, bounded priority queues (CRITICAL retried with backoff or flagged degraded, LOW coalesced/dropped with counters), disk-full degradation that never crashes or silently drops terminal events, and a TTY mirror that replaces the old prints. `scripts/v2/view_events.py` renders the human view (UTC/local display) and writes the content-free redacted export. Third-party stderr (tqdm, download progress) is captured into bounded, content-free diagnostic records around model loads.
2. **Persistent store (Spec S08, EV-03).** `localflow/v2/store.py`: single-writer SQLite `~/Library/Application Support/LocalFlow/v2.db` (store schema v2 = v1 tables + hot-path indexes; `training_schema_version` 1), per-op transactions with backup-before-migration, loud refusal on malformed core tables, idempotent repair for lost tables. Jobs follow the contract state machine (idempotent, stale-discard, exactly-one terminal outcome); artifacts are immutable with sha256 and exact metadata; audio persists as lossless IEEE-float32 WAV (S29.5). The legacy `dictations` compatibility view sits over verbatim `legacy_dictations` rows.
3. **Lossless import.** `localflow/v2/importer.py` + `scripts/v2/import_legacy.py`: stats.db imported from a verified SQLite backup (never the live file), dictionary/transforms as legacy-revision artifacts, log pairs as unknown-date artifacts with identity `legacy:<sha>:<line-range>`; atomic artifact+bookkeeping ops make crashes converge on re-import; appended logs reconcile by verified byte prefix. **Real run:** 7 rows (280/277/350.3/11, instants 2026-07-04T21:15:42.804Z–21:38:40.276Z preserved), 7 terms, 2 transforms, 754 log pairs; re-run adds zero rows; sources byte-identical; consistency ok.
4. **Training evidence (Spec S29.1–S29.4, EV-19 initial).** `localflow/v2/training.py`: opt-in consent revisions (absent = disabled — nothing is collected until the user chooses it), live collector around the existing ASR/cleanup stages (audio attached before model execution; exact rendered prompts retained byte-for-byte; raw/proposal/applied artifacts with parent links; append-only revisions; family IDs; `posted_unverified` outcome per the targets contract), honest missing reasons for every later-milestone field family, secret quarantine (content-free events), leases (30-day training buffer, pinned survives, 7-day history can't override), 30-day unreviewed-buffer expiry, delete-everywhere with content-free tombstones, orphan sweep with grace. Minimal menu surface: Collect Training Evidence / Pause Collection / Exclude Last Dictation / Mark Last Dictation Correct.
5. **Pipeline wiring.** `app.py` prints → events; jobs minted at hotkey-down per the contract; store/collector calls guarded so a store stall or evidence-write failure can never drop a dictation; retention runs off-main daily. `cleanup.py` gained optional notifier/observer hooks (behavior verified unchanged: 51/51 model-backed cases). `config.py` gained the S25 retention knobs (visible, adjustable).

### Decisions stated explicitly

- **Pause semantics (capture snapshot).** Consent in force at push-to-talk DOWN governs that capture. A later enable never authorizes earlier audio; a pause after capture start does not revoke the in-flight capture; delete-everywhere is the separate, immediate barrier; a recovery retry collects only with the original capture's permission AND collection enabled now. Recorded in `contracts/training_evidence.md`.
- **Authority.** The store is the durable authority for job/evidence state; events are diagnostic records emitted after commits, not a transactional replica.
- **Timeouts are not cancellation.** A waited store call's `TimeoutError` leaves the op queued; ids are pre-allocated so a late commit is joinable (tested).
- **Ownership is never guessed.** Only job-named debug copies and `job-<id>.*` journal files are deleted with a job; legacy timestamp-only debug copies keep their rotation.
- **History is not rewritten.** Old `user_explicit` marks stay as recorded; unknown provenance stays unknown; pre-v11 deletions get a barrier via content-free backfill (`pre_v11_deletion`).
- **Schema v11** is additive (`job_deletions`, `purge_intents`); a store with a newer version is refused; a missing core table with surviving dependents is backed up and refused.
