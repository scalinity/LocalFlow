## What shipped

1. **The context package (Spec S12, EV-08).** `localflow.v2.context`: `TargetSnapshot` (cheap frontmost identity via NSWorkspace — bundle/pid/name, denied decision, category; NO Accessibility on the hotkey path), `ContextSnapshot` (identity + field/selected/nearby text + origin + workspace + identifiers + provenance + freshness + per-provider status/duration + omission reasons; immutable; `to_json` for artifacts, `to_envelope_block` content-free), providers behind an injectable `SystemAXHost` (messaging-timeout-bounded AX reads; one cached systemwide element) and `frontmost` accessor, and `ContextCollector` (identity → async collection during recording → bounded finalize at release, deadline `context_deadline_ms` default 75; partial on cut; per-job collection handles; downstream revisions; short-lived origin/workspace cache invalidated on app/focus/window change).
2. **Sensitive-field absolutes (S12).** Classify-before-read (role/subrole decide `secure|text|unclassifiable|none` before any content attribute); secure fields retain no content anywhere; unclassifiable fields get plain dictation without nearby text; denied apps are never read at all (including their origin/window title — review-fixed); browser origins strip query/fragment (`AXURL` source, marked window-title fallback with a plausible-host check, honest `not_exposed` otherwise); placeholders are metadata never text; no filesystem reads (document locators are recorded strings; only `file://`/absolute paths yield workspaces); nearby reads bounded (600 chars) and identifiers capped (64).
3. **One snapshot, three consumers (the settled wiring).** The finalized `ContextSnapshot` feeds: the M05 `ScopeContext` (app/site/workspace — profile stays None until M10), the M04 engine `ContextSnapshot(destination_app, path_context, identifiers, vocabulary)` (the job's frozen vocabulary rides through), and the S30.1 `context_snapshot_id` in `asr_hint_request_fields` (called on the real dictation path now; None under the unqualified adapter).
4. **Pipeline wiring (app.py).** Identity captured after the overlay, before the M05 trio (trio scoped by the app identity); collection runs during recording; finalize + **scope upgrade** at release, before `job_started`/`on_hint_set` — when the resolved origin/workspace widen the scope, the trio rebuilds from the job's **frozen entry set** (no store read; M05 AC03 preserved live) and the upgraded hint set is what is stored pre-decode. Late provider results are picked up by the coordinator as a separately-identified downstream revision via the job's own collection handle. Every context call is guarded — a context failure degrades to less context with an event, never a dropped dictation.
5. **Evidence (S29.4 context family; S29.14).** `EvidenceCollector.on_context_snapshot` writes the full snapshot JSON as a lease-governed artifact (`pre_decode_context`/`downstream_context`) and fills the envelope's content-free `context.destination`/`context.downstream` blocks; the absent halves carry honest reasons. Retention is the independent `training_retain_context` knob: off ⇒ no payload (pre-decode and downstream), `retained: false` + reason + `missing_reasons.context_snapshot_payload` marking replay inputs incomplete.
6. **Config (S25-visible).** `context_enabled` (default true), `context_deadline_ms` (75), `context_denied_apps` ([]), `training_retain_context` (true).
7. **Diagnostics.** Content-free events (`context.snapshot_finalized` with coverage counts/durations, `context.cache_invalidated`, `context.identity_unavailable`, `context.capture_failed`, `context.finalize_failed`, `context.collector_unavailable`, `context.provider_failed`, `context.destination_changed`); plain dictation remains available in every degraded mode (tested through the real coordinator).

## Contracts and decisions

- New `contracts/context.md` (capture structure, one-snapshot-three-consumers, sensitive-field absolutes, freshness/caching, degradation, evidence retention, hosts/testability, limitations). `contracts/INDEX.md` row + decision note; `targets.md` snapshot half live; `vocabulary.md` M06 wiring + limitation update; `asr_hints.md` M06 live status; `normalization.md` dependency live; `training_evidence.md` M06 live status. No frozen identifier changed; registry stays 33/22; no ADRs — no spec deviation accepted.
- **Where the S12 bounded snapshot is captured (settled, per the kickoff):** identity at PTT-start (post-overlay, NSWorkspace only); async collection during recording; bounded finalize (≤75 ms) at release in `_finishCapture`, **before** `job_started`/`on_hint_set`/enqueue — everything context-related is pre-decode by construction, ASR starts strictly after, and late providers surface only as downstream revisions. Reason: the spec's own structure ("inexpensive target identity at PTT start; collect asynchronously while recording; finalize a bounded snapshot at release", "initial post-release deadline is 75 ms") and M05's freeze semantics (the hint set must be scoped by the destination before decoding; the evidence write already sits after the finalize point).
- **Partial degradation:** timed-out providers are omitted with reason `deadline` (`provider_failed` for exceptions, `destination_changed` for frontmost drift, `permission_unavailable`/`ax_messaging_failed` for AX states); `partial` is true for genuine degradations, not for a legitimate `not_exposed`.
- **Scope upgrade from frozen entries (not the store)** — the AC03-preserving rebuild; a mid-flight dictionary edit changes only future jobs (tested live).
- **Jobs table carries no `target_snapshot_id` column** (settled): the ids live on the job dict and in the evidence context block; M08 adds what insertion validation needs at its own migration. No speculative schema.
- **Window-title origin fallback** is provenance-marked heuristic with a plausible-host check; browsers that expose no AXURL report no origin rather than a guess.
- **`profile` scope stays unfed live** — no writing-profile subsystem exists before M10; profile-scoped entries apply only in tests/the sandbox.

## /review-2 → /address record

`/review-2` ran two parallel read-only reviewers (bug-hunting debugger; architecture/quality/security/data-integrity auditor). Verdict before addressing: **Request Changes** — 2 criticals, 7 warnings, 11 suggestions after dedup. The criticals: (1) **corroborated by both reviewers** — a denied app that is a browser was still read by the site-origin provider and its origin persisted into retained artifacts, violating the S12 denied-app absolute (the existing test used an unknown-category app and missed the leaking class); (2) collector state was global, not per-job — a failed identity capture could finalize the previous dictation's snapshot into the new job's evidence, and `take_downstream` could attribute a newer dictation's late context to the job still processing.

`/address` fixed both criticals and every warning in-session with regression tests: denied gates end-to-end (provider params + composition hard-null + denied-browser fixture/test with zero-read and no-leak assertions); per-job collection handles (begin returns the handle, finalize refuses stale/foreign targets, abandon on failed identity, one-shot downstream from the job's own handle); honest absent-destination envelope marker; provider exceptions recorded as `provider_failed` + event (never a fake deadline) and downstream rows marked `not_in_revision`; locals-first scope upgrade; `is_path_document` scheme gating (http URLs never yield workspaces/path_context); plausible-host title fallback with an extension denylist; destination-drift check before content reads; and all flagged test gaps closed. Ten suggestions applied (dead-symbol removal, `_PARTIAL_REASONS` from constants, generator→plain collection method, cached systemwide AX element, tolerant `from_json`, real call site for `asr_hint_request_fields`, cache locking, isinstance guards, comment alignment — see results.json `review_loop.addressed`). One deferred with its reason: a seventh envelope missing-reason value for the retention knob — the six-value vocabulary is frozen in `contracts/artifacts.md` and the precise `training_context_retention_disabled` reason already lives in the destination block; changing frozen vocabulary needs its own contract decision. **No findings rejected as incorrect.** Post-address, every suite and both model-backed checks re-ran green and the benchmark was re-run on the fixed code. (The /address per-fix-commit cadence was adapted to this repo's milestone protocol: one close-out commit, no push — per the kickoff's explicit constraints.)
