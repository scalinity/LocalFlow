2. **The Scratchpad Hub view (VIEWS 8→9, the M09 triple).** Notes list + search, tab strip, the `ScratchpadEditor` NSTextView bound to a pure-Python `NotesEditorModel` (serialized flushes — concurrent autosave can never interleave revisions; debounced autosaves off the UI thread; note switches flush the outgoing buffer), versions popup + Restore (copy-forward, editor rebinds so the next keystroke builds on the restore — AC02), the transform picker, Snapshot, Add Image…, exports, Pin, Delete.
3. **Dictation into the note — the internal destination.** A PTT start with the editor as the key window's first responder binds the job (note id + insertion point captured at hotkey-down, the M08 promise discipline). `_finishWithText_` delivers at that anchor as an immediate `dictated` revision with `source_job_id`; the job records `insertion_confirmed/scratchpad_note`. **The M08 external queue is never involved** — a closed/changed note routes to `saved_not_inserted/note_closed_during_dictation` with the clipboard offer, never a paste elsewhere (the M12 regression requirement, pinned both ways).
4. **Note-scope transforms + Save-to-Scratchpad (S16/S20).** The picker's definition over the selection, or the WHOLE NOTE — the coordinator coerces a range-less note capture to `(0, len)` so accept REPLACES the note; accept revalidates the captured source (`note_range_changed` → copy offer). Revisions record the M11 task identity; candidates carry `task_kind=transform_note`. The preview panel's honestly-disabled Save-to-Scratchpad is live (the output becomes a new note with task identity).
5. **History copy/move + quick-open (S20 task 4).** `hubSaveHistoryRow` reads the retained final text (applied → cleaned → raw); V2 jobs attribute `source_job_id`, legacy rows are honest `typed`; move applies delete-everywhere to the job and a legacy move degrades honestly to copy (legacy history is lossless by contract). Quick-open is one status-menu action (Hub + Scratchpad + fresh note) behind the same focus-steal guard as Open Hub, with the deferred intent carried to the settle flush.
6. **Export + evidence.** Markdown/plain through the M07 `document_nodes` renderer (AC03: supported structure preserved, unsupported elements reported and never silently dropped; a failed export cleans its partial files and retains the note). The S29.8 note family: content-free `notes` observations appended to existing examples' envelopes behind consent, `note_evidence_links` closed on deletion, repeated revisions never mint examples or duplicate counts, typed additions never labeled dictated (AC05; AC04 pinned with sockets disabled).

## Reusable patterns for M13+

- **The internal destination pattern:** a PTT-time binding (identity + anchor captured at hotkey-down, enforced at delivery, mismatch → the saved-not-inserted fallback) is how any future internal surface (Insights drafts, M14 review panes) should receive dictations — the external queue stays external-only.
- **Rebind-when-moved:** a view bound to a store row should rebind whenever the persisted row moved under a CLEAN local buffer — dirty wins, and the tail flush lands after; this closed the whole restore/tab-switch/stale-editor class in one guard.
- **One loader generation per select:** list+detail loads sharing a generation cannot supersede each other — the just-created row actually appears; the M10/M11 views' back-to-back reload+select would benefit if they ever show the same staleness.
- **Fail fast on dead writers:** a closed single-writer store should reject submits instantly; a 15-second hang masked as a "wedge" costs an hour of debugging that a millisecond error message ends.
