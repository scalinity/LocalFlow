## What shipped

1. **Fresh-subprocess model worker (Spec S06, EV-05).** `localflow/v2/worker.py` runs ASR + cleanup in a spawned process (`python -m localflow.v2.worker`) — never a fork of Metal state; the parent holds no MLX. Versioned (v1) length-framed JSON protocol on inherited pipes; audio is a parent-created file name under a root fixed at spawn, validated to a single path segment; **the protocol has no insertion op** and unknown worker→parent ops are ignored. `localflow/v2/supervisor.py` owns generations, per-request identity (req_id + generation + attempt), one automatic retry on a fresh worker with attempt+1, a 3-death circuit breaker that only a manual restart re-arms, GPU serialization (one in-flight request), pipe-death resolution of pendings, and stale-result discard (both unknown-request and stale-generation echoes). Workers always run with `HF_HUB_OFFLINE=1`: cache misses fail loudly (install via `scripts/warmup.py`), never a mid-dictation download.
2. **Durable capture journal (Spec S09, M03-AC03, EV-04).** `localflow/v2/capture_journal.py`: the audio callback only enqueues (bounded 256, non-blocking); one writer thread owns all disk; files are lazy so the hotkey path does no disk work. Crash reconstruction returns every complete block bit-exact and labels the torn tail; disk-full/queue-flood degrade with counted drops while the in-memory capture path continues. Startup scan rebuilds crashed journals and finalized-but-unresolved wavs (previous boots only) into `failed_recoverable` Recovery items; below-min residue is cancelled; unresolved journal files expire by mtime with the audio-failed retention knob.
3. **Lifecycle wiring.** Sleep/lock end capture with a recoverable item and wake never reopens the mic (M03-AC04). A dead stream/vanished device finishes the dictation with the captured speech and records the discontinuity. Cancellation during processing removes insertion authority immediately — late worker results never paste or double-count, and journal-file deletion waits until the coordinator is done (a cancel can no longer fault a healthy worker). The Fn lost-release watchdog is preserved, is now hands-free-aware, and tracks the trigger that started the capture (hotkey or non-primary mouse button, both with `physically_down` recovery). Configurable additions, default-off: hands-free double-tap, middle/right mouse PTT; plus `capture_journal` (memory-only mode honestly disables crash recovery) and `cleanup_not_ready_policy` (basic-now vs bounded hold; the recorded path is always the path that produced the text — basic is never labeled LLM-cleaned, and a cleanup engine whose load failed reports `failed`, not `ready`).
4. **Audio fidelity + honest nulls (S29.5/S30.1, M03-AC05/AC06, EV-18/EV-19 producer subset).** Original artifacts stay bit-exact float32; PCM16 exports are parent-bound derivatives labeled `lossless:false`; decode ranges are original-sample half-open bounds joined to the parent artifact, with journal drops/incomplete tails surfaced as explicit discontinuities; a failed audio write reports `not_captured_at_stage` (never consent-disabled) with `Store.verify()` extended to catch dangling joins. `localflow/v2/capabilities.py` ships the conservative manifest: all eight optional capabilities False-with-reason-and-evidence (biasing/key-terms `disabled_until_qualified`), hint disposition content-free, envelope optional-ASR reasons `unsupported_by_adapter`. Envelope gains `attempt`, `worker_generation`, `audio_preparation`, `cleanup.applied_path`.
5. **Recovery UI + engine status.** Recovery menu (Retry Last Failed Dictation / Copy Raw Transcript of Last Failure), a brief failed-pill state, per-engine status line ("ASR: ready · Cleanup: loading"), and retry re-opens `failed_recoverable → queued` with attempt+1 — the one deliberate terminal-state exception.
