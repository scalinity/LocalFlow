## What shipped

1. **The native Hub shell (S19, tasks 1+5).** One AppKit window (1100×760 clamped, min 900×620 clamped, native frame autosave, close ≠ quit, single instance) with a persistent sidebar (Home / History / Diagnostics / Models / Settings) bound to `HubState` — a pure-Python, AppKit-free view-model that owns all view/selection/search state. Queries run on one daemon query thread and publish through `AppHelper.callAfter`; searches are cancellable by generation. No view owns data logic; every action is a coordinator command.
2. **Searchable history (task 2).** `HistoryQueryService` reads the single-writer store (one materialized `Store.submit` op per query): local-date grouping newest-first with the explicit **Undated** group for legacy log imports (S21), text search (escaped LIKE over raw/normalized/applied artifacts via a SQL subquery), app filter (V2 jobs via the new `job_targets` rows; legacy halves carry no app and are excluded under an app filter), mode filter (`json_extract` over the applied artifact's `cleanup_path`, fixed vocabulary). The lineage detail is four distinct stages — the transform slot says `not_applicable_until_M11` (AC01).
3. **Replay, stage diff, copy/paste-again, retry (task 3, AC02).** `ReplayService` renders an in-memory PCM16 derivative (the float32 original is never touched), stops the previous item, and reports honest reasons for missing/purged audio. History's Paste Again is the M08 reconcile-then-submit engine generalized to `InsertionService.paste_text(text, job_id, on_done)` — the row's job id keeps the `insertions` attribution. Retry runs through the shared `_retry_job` with `already_retrying` / `not_retryable` / `audio_unavailable` guards (a double click never double-inserts).
4. **Diagnostics + engine states (task 4).** Event reading over the same JSONL the writer persists (UTC/local display, job/level filters, bounded window), job timelines, the engine/build block (model ids/revisions, runtime, config hash), and the content-free redacted export bounded to the displayed filtered window.
5. **Models → Training Data (tasks 6–8, S29.15, AC05/AC06).** The inspector lists examples with completeness/missing-reason summaries and honest audio availability; the detail resolves stage texts from retained artifacts, shows the context block's omission reasons (secure fields display their reason — no content exists to leak), the revision chain and every annotation. Annotations are ONE atomic writer op each (artifact + lease + revision + state) with payload text in lease-governed artifacts and content-free envelope entries: `mark_intended` (provenance-separated whole-example judgment), `set_verbatim` (audio-reviewed only — the service refuses without listening, E14, and the Hub's gate is per-example), `add_span_correction` (code-point offsets validated against the stage's exact text; `coverage: partial` forever; whole-example correctness untouched — AC05). Pin/unpin scope to non-annotation artifacts (annotation payloads carry their own review retention, S29.14). Exclude restores refuse to resurrect expired/quarantined/deleted states. Delete-everywhere is the store contract. Readiness separates infrastructure / dataset coverage / observed improvement (explicitly post-V2). Settings exposes collection enable/pause/disable and the five retention knobs (applied immediately to the store, persisted into the user override for the five keys only).

## Reusable UI/service patterns for M10–M13

- **Build on `HubState`, not the shell.** New views register in `VIEWS`, get a `_blank_view` state, a `_build_<view>_view` + `_refresh_<view>_view` pair on `HubController`, and a `_load_<view>` query on the state — keyboard/selection/close-reopen/single-instance come free. Future features refuse at state level until they exist (no placeholder tabs).
- **Query services:** one materialized `Store.submit` op per query; mutations ONE op with the shared `insert_text_artifact_row`/`grant_lease_row` INSERTs; publish through the query thread + `callAfter`; cancellable by generation.
- **Coordinator commands only** for anything touching the world (`hub*` methods); the focus-steal guard (`busy`/`_injecting`/recording with settle-time flush) is the pattern for any future window action that could race an insertion.
- **Honesty idioms to copy:** absent stage → reason, never a copy; missing audio → reason; per-example gates for provenance-bearing controls; pin vs review-retention separation; readiness triads that never fabricate the third bucket.
